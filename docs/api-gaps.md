# فجوات الربط بالخادم — تُحدَّث مع كل مرحلة

يُسجَّل هنا كل مسار أُنشئ بتطبيق وهمي (mock) لأن الخادم لم يكن يوفّر شكل البيانات الذي يحتاجه البروتوتايب وقت البناء، وفق القسم ٩ من برومت إعادة بناء الواجهة.

| الشاشة/الميزة | الحالة | ملاحظة |
|---|---|---|
| الشريط العلوي — شريحة الفصل الدراسي | نص ثابت | "الفصل الأول ١٤٤٧ · الأسبوع ٩ من ١٥" مكتوب مباشرة في `Topbar.tsx`. يحتاج مسار فعلي يُرجع الفصل/الأسبوع الجاري من التقويم الأكاديمي. |
| البحث الموحّد — مجموعة «المقررات» | بيانات وهمية | مصدرها `src/mock/courses.ts` (منسوخ من `COURSES` في البروتوتايب). يحتاج مسارًا يُرجع مقررات المستخدم الفعلية. |
| مركز الإشعارات | بيانات وهمية + حالة محلية فقط | القائمة الابتدائية من `src/mock/notifications.ts`؛ «تعليم الكل كمقروء» يُغيّر حالة محلية في `AppShell` فقط، بلا استدعاء خادم. يحتاج WebSocket/polling حقيقي ومسار تعليم كمقروء. |
| تسجيل الدخول (`LoginPage`) | غير موصول بالخادم | النموذج يتحقق فعليًا بمخطط `loginSchema` المشترك، لكن الإرسال عند النجاح يُدخل مباشرة كعضو هيئة تدريس (`navigate` فقط) بدل نداء `POST /auth/login` الحقيقي. يحتاج ربطًا بالمرحلة ٧ يقرأ الدور الفعلي من رمز JWT بدل افتراضه. |
| أزرار معاينة الأدوار في شاشة الدخول | أداة مراجعة داخلية فقط | تدخل مباشرة بأي دور بضغطة زر بلا مصادقة — مقصودة في البروتوتايب للمعاينة الداخلية فقط ("ادخل بدور آخر للمعاينة"). **يجب حجبها خلف صلاحية إدارية أو حذفها قبل الإنتاج** — لن تُترك متاحة للجمهور. |
| التسجيل (`SignupPage`) | غير موصول بالخادم | يتحقق محليًا فقط، ولا ينادي `POST /auth/register` الحقيقي بعد. |
| التسجيل — حقول الرتبة/القسم/الجامعة (عضو هيئة تدريس) | خارج مخطط `registerSchema` الحالي | `registerSchema` في `packages/shared` يقبل حاليًا `fullName/email/password/role` فقط. حقول الرتبة العلمية والقسم والجامعة (موجودة في نموذج البروتوتايب البصري) تحتاج توسيع Prisma (نموذج ملف تعريف عضو هيئة التدريس) والمخطط المشترك، أو خطوة "إكمال الملف الشخصي" منفصلة بعد التسجيل الأساسي. |
| التسجيل — عضو هيئة تدريس: استيراد ملف الجدول | رفع حقيقي محليًا، بلا معالجة فعلية | حقل الملف والسحب والإفلات فعليان (يلتقطان `File` حقيقيًا)، لكن لا يوجد بعد مسار خادم يستقبل الملف ويحلّله وينشئ المقررات/الشُّعب تلقائيًا (القسم ١٣ من `mihwar-build-prompt-v3.md`). |
| التسجيل — طالب: مطابقة كود الشعبة | محاكاة محلية عبر `src/mock/courses.ts` فقط | `matchCourse()` في `SignupStudentJoinStep.tsx` يبحث في القائمة الوهمية المحلية فقط لعرض تأكيد فوري؛ يحتاج مسارًا حقيقيًا للتحقق من كود الشعبة عند الخادم. |
| صفحة الهبوط — «استعرض المنصة» | يدخل مباشرة كعضو هيئة تدريس | يتصرف كاختصار عرض توضيحي (toast يوضّح ذلك)، لا دخول حقيقي. يجب أن يُستبدل بجلسة تجريبية حقيقية (sandbox) أو يُزال عند اكتمال الربط الفعلي. |
